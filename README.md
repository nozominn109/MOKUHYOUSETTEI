## 2年後のゴール（2028年10月末）

- つながり総数 10,000人 ＝ Instagram 4,500 ＋ Threads 4,500 ＋ LINE 1,000（重複して数える）
- お役立ちお茶会・ランチ会 累計90回／延べ800人、会を開く仲間 10人
- 親子AI体験会（福岡）累計120組
- 月収50万円以上（最低ライン。計画どおりなら2028年6月に到達、10月は約60万円）／夢は200万円
- AiNAフリープラン登録600人、有料会員（直紹介）150人、紹介する仲間30人、チーム全体の有料会員900人
- 企業へのAI提案60社 → 成約12社

月収は、AiNAアフィリエイトのオパールの報酬率（入会金30%・月額20%、サブアフィリエイト15%・5%、2〜4段階先 月額2%）で、有料会員の3割がエキスパートを選ぶ前提で計算しています。
