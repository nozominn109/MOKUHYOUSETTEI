# きょうのひとつ（試作）

大人の非認知能力を、12週間で1つ練習するためのスマホ用Webアプリの試作です。

- 画面は3つ：今日の行動／夜の記録／振り返り
- 最初に「伸ばしたい力」を1つ選び、「なりたい自分」を一文で書く
- 開始時と12週後に同じ自己チェック（8問・5段階）をして比べる
- 通知はiPhoneのリマインダー（朝1回・夜1回）で行う

## データについて
- 記録はiPhoneの中（ブラウザの保存領域）だけに保存し、外部には送りません
- このフォルダには、アプリのコードだけを置きます。記録データやバックアップファイルは置きません
- 「設定」からバックアップ（JSONファイル）を書き出し・読み込みできます

## 注意
- 医療や診断のためのものではありません
- 自己チェックの質問はこのアプリのために作ったもので、研究で検証された尺度ではありません
