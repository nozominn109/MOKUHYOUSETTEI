# 未定　ショート「朝7時。『起きなさい』もう3回目」（15秒）

- 状態：ストック（骨組み・15秒版）。11/21にウィルの台本「上の子ばっかり怒っちゃう」と入れかえたため、日にち未定
- 投稿：11/23（月・勤労感謝の日）20:00。連休最後の夜＝「明日の朝、起きるかな…」の親に届きやすい
- ねらい：親テーマ（中学生の親）。11/13・11/16と同じ型で、親世代の割合がそろうかを見る。判定は年齢構成（翌朝の数字）と Reels skip rate
- 動画ファイル：田中家のセッションのGitHub（nozominn109/Instagram-DOUGA）の「投稿ライブラリ」の同じ名前のフォルダ（前は「未定_ショート_朝7時起きなさい3回目」）

親の悩み：毎朝、何度起こしても起きない中学生。声がどんどん大きくなって、朝から親がぐったりする
使う考え方：課題の分離（起きるのは本人の課題）。起き方は、本人と話して決める
場面：夜のリビングだけ（1シーン）。0〜3秒だけ朝の階段の絵（新しく1枚）

| 秒 | 中身 |
|---|---|
| 0〜3 | 文字「朝7時。『起きなさい』もう3回目」（0秒目から）。階段の下で声を張る愛奈 |
| 3〜7 | その夜のリビング。愛奈がスマホにお願い → 大きな字幕でAIの問い「どうしたら、自分で起きられそう？…と本人に聞いてみては？」（1秒長め）。保存バナー「全文はキャプションに。保存してね」を小さく |
| 7〜11 | 愛奈がその問いを蒼に。蒼、目をそらして【②】 |
| 11〜15 | 【③】→「田中家の続きは平日20時。フォローしてね」 |

- 家の中なので全員靴なし。蒼はシャイ（目をそらす、頬づえ）。AIラベルをオン
- 体の不調で起きられない子もいるので、「起きない子＝だらしない」に見える描き方はしない

お願いの文（キャプションに）：
「中学生の親です。毎朝3回起こしても起きません。子どもが自分で起きる方法を、本人と話して決めたいです。私から子どもにする質問を3つ考えて」

### 選んでほしいこと
① 0秒目の文字：A「朝7時。『起きなさい』もう3回目」／B「連休明けの朝、また『起きなさい』3回？」／C「毎朝、何回起こしてる？」→ おすすめA（時刻＋数字＋困りごと。B は祝日の夜らしいが、文字が長い）
② 蒼が自分で決めること：A「…目覚まし、2個にする」／B「起こすのは1回だけでいい」／C「…カーテン、開けて寝る」→ おすすめB（愛奈も「1回だけね」と変わる。課題の分離がいちばん伝わる）
③ 最後：A 蒼「…1回で起きるから」愛奈にっこり／B 哲「僕は3回起こしてほしい」愛奈「パパは自分で起きて」／C 愛奈の心の声【希が書く】（方向性：起こすのをやめるんじゃなく、任せてみる）→ おすすめB（1場面のまま笑って終われる）

### 希に聞きたいこと
1. 子どものころ、朝はどうやって起きていた？ 起こされて、どんな気持ちだった？
2. 毎朝起こす側として、いちばんしんどいのはどんなとき？

キャプション案（たたき台）：
毎朝、子どもを何回起こしていますか？⏰
「起きなさい」が3回目になると、朝からこっちがぐったり…。

田中家のママがAIに聞いたのは「起こし方」ではなく、「息子に何を聞けばいい？」でした。
決めたのは、蒼。
