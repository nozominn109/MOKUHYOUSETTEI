## 決定稿（11/7・希と作成）
希が決めたこと：哲は「スタンプだけでよくない？」→ 愛奈「ダメ！」／AIの下書きのあと、AIが「ひとこと足すなら？」と聞いて愛奈がハッとする／足すのは蒼の言葉「車の中、楽しかった」／最後は相手からの返信で、愛奈がにっこり

| 秒 | 中身 |
|---|---|
| 0〜2 | 文字「部活の保護者LINE、お礼の一文に30分…」。愛奈がスマホで書いては消す |
| 2〜4 | 哲がのぞきこんで「スタンプだけでよくない？」愛奈「ダメ！」 |
| 4〜7 | スマホ画面のアップ：吹き出し「送迎のお礼の文、3行で」→ AIの下書き「昨日は送迎を代わっていただき、ありがとうございました！／本当に助かりました。／また何かあれば、お声がけください。」 |
| 7〜9 | AI（画面の文字）「最後に、愛奈さんの言葉でひとこと足すなら？」→ 愛奈ハッ |
| 9〜11 | 回想（リビング）：蒼が目をそらしたまま、ぼそっと「…車の中、楽しかった」 |
| 11〜13 | 愛奈が打ち足す「蒼が『車の中、楽しかった』って言ってました」→ 送信 |
| 13〜16 | ピコン。返信「蒼くん、そう言ってくれてたんですね😊」→ 愛奈がにっこり →「田中家の続きは平日20時。フォローしてね」 |

- 家の中なので全員靴なし。蒼はシャイ。AIラベルをオン
- 相手の名前やアイコンは出さない（ぼかす）。トーク画面は実在アプリのロゴを出さない「LINE風」で
- AIの下書きは決まり文句っぽく、愛奈が足すひと言だけ温かく見えるように（文字の色や動きで差をつけてもよい）

キャプション案：
部活の保護者LINE、お礼の一文に30分…📱
丁寧すぎると重いし、短すぎると冷たい。わかる…。

下書きはAIに。
でも最後に「ひとこと足すなら？」と聞かれて、思い出したのは蒼のひと言でした。

決まり文句の3行より、自分の言葉のひと言のほうが、ちゃんと届く。
