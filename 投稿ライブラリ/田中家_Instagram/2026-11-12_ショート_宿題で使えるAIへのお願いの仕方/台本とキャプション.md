## 決定稿（11/7・希と作成）
希が決めたこと：第1話とは別の新しい話にする／宿題は算数の文章題（「答えは言わずにヒントだけ」のお願い）／莉奈が自分で解けたら、愛奈「すごいじゃん！」とほめて、心の声の吹き出しで「答えより、"わかった！"のほうがうれしいね」／1コマ目の問いは「宿題、AIにやらせたらズル？」

| 秒 | 中身 |
|---|---|
| 0〜2 | 文字「宿題、AIにやらせたらズル？」。莉奈が算数ドリルの前でスマホを持って「AIに答え聞いちゃお」 |
| 2〜4 | 愛奈（となりに座って）「待って。聞き方を変えてみよう」 |
| 4〜8 | スマホ画面のアップ：吹き出し「答えは言わないで。ヒントを1つずつ出して」→ AI「まず、3日間で全部で何ページ読んだかな？」 |
| 8〜11 | 莉奈「12＋15＋18で…45！ それを3日で分けると…15！」 |
| 11〜13 | 莉奈「自分で解けた！」 愛奈「すごいじゃん！」 |
| 13〜15 | 愛奈がにっこり。心の声の吹き出し「答えより、"わかった！"のほうがうれしいね」 |
| 15〜17 | 文字「AIに"答え"じゃなく"ヒント"をもらう」→「田中家の続きは平日20時。フォローしてね」 |

- ドリルの問題：「3日間で読んだページは12・15・18ページ。1日平均何ページ？」（小5の「平均」）。問題の文字は、絵の中に作らせず編集で文字を乗せる（AIの絵だと日本語がくずれやすい）
- 莉奈がスマホを使う場面は、必ず愛奈がとなりにいる（小学生は親と一緒に使う）
- 家の中なので全員靴なし。AIラベルをオン
- 心の声の吹き出しは11/10と同じ見せ方（愛奈の"心の声"の定番に）

キャプション案：
宿題、AIにやらせたらズル？🤔

答えを聞くだけなら、ズルかも。
でも「答えは言わないで、ヒントだけ」とお願いすれば、AIは一緒に考える相棒になります。

自分で解けたときの「わかった！」は、答えをもらうより、ずっとうれしい。

📝 そのまま使えるお願いの文（保存してね）
「小学5年生の算数の宿題です。答えは言わずに、考え方のヒントを1つずつ出してください。私が答えたら、合っているか教えてね」
※小学生のうちは、親と一緒に使ってね（多くのAIは13歳以上が対象です）

一緒に子育てしている人に送ってね。
