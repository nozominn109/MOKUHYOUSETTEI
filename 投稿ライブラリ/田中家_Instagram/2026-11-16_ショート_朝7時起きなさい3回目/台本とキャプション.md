# 11/16（月）ショート「朝7時。『起きなさい』もう3回目」（15秒）

- 状態：骨組み（11/13の金曜の自動作業）。希が①②③を選んで台本を決める
- 動画ファイル：田中家のセッションのGitHub（nozominn109/Instagram-DOUGA）の「投稿ライブラリ」の同じ名前のフォルダ

親の悩み：毎朝、何度起こしても起きない中学生。声がどんどん大きくなって、朝から親がぐったりする
使う考え方：課題の分離（起きるのは本人の課題）＋「任せたよ」。起き方のルールは、本人と話して決める

| 秒 | 中身 |
|---|---|
| 0〜2 | 文字「朝7時。『起きなさい』もう3回目」（0秒目から）。愛奈が階段の下で声を張る |
| 2〜4 | 2階から蒼の声だけ「…起きてる」（布団の中）。寝ぐせの哲が出てきて「僕も起きてるよ」愛奈「パパは聞いてない」 |
| 4〜8 | 前の日の夜。スマホ画面のアップ：お願いの文 → AIの問いを大きな字幕で「どうしたら、自分で起きられそう？」（1秒長めに止める。「全文はキャプションに。保存してあとで試してね」を小さく） |
| 8〜12 | リビング。愛奈がその問いを蒼に。蒼、目をそらして【②で選ぶ蒼の答え】 |
| 12〜15 | 【③で選ぶ最後】→「田中家の続きは平日20時。フォローしてね」 |

- 愛奈の想い【ママの想い：希が書く】（方向性：起こすのをやめるんじゃなくて、任せてみる。決めたのは蒼）。心の声（吹き出しの文字）にしてもよい
- 家の中なので全員靴なし。蒼はシャイ（目をそらす、頬づえ）。AIラベルをオン
- 体の不調で起きられない子もいるので、「起きない子＝だらしない」と見える描き方はしない

お願いの文（親の一人称）：
「中学生の親です。毎朝3回起こしても起きません。子どもが自分で起きる方法を、本人と話して決めたいです。私から子どもにする質問を3つ考えて」

## 選んでほしいこと
① 0秒目の文字
- A「朝7時。『起きなさい』もう3回目」
- B「毎朝、何回起こしてる？」
- C「朝7時。3回起こしても起きない」
- おすすめ：A（時刻＋数字＋困りごとの型。愛奈の声と重なって、一瞬で場面が分かる）

② 蒼が自分で決めること
- A「…目覚まし、2個にする」（1個は部屋の向こう）
- B「起こすのは1回だけでいい」（親子の約束）
- C「…カーテン、開けて寝る」
- おすすめ：B（愛奈も「1回だけね」と変わる。課題の分離がいちばん伝わる）

③ 最後の3秒
- A 次の朝7時、蒼が自分で下りてくる「…おはよ」。愛奈にっこり
- B 起きられなかったけど、蒼が自分で「ごめん」と言って走って出る（失敗してもOK）
- C A のあと、哲だけ寝坊。「なんで起こしてくれないの！」愛奈「自分で起きてね」
- おすすめ：C（蒼の成長と、哲のオチで笑って終われる）

## 希に聞きたいこと
1. 子どものころ、朝はどうやって起きていた？ 起こされて、どんな気持ちだった？
2. 毎朝起こす側として、いちばんしんどいのはどんなとき？

キャプション案：
毎朝、子どもを何回起こしていますか？⏰
「起きなさい」が3回目になると、朝からこっちがぐったり…。

田中家のママがAIに聞いたのは「起こし方」ではなく、「息子に何を聞けばいい？」でした。
決めたのは、蒼。
