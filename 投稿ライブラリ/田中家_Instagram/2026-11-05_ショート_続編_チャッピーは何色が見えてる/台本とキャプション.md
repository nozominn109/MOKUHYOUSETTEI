| 場面 | 内容 |
|---|---|
| 1コマ目 | 文字「昨日の続き…莉奈の"知りたい"が止まらない！」 |
| ① | 莉奈「じゃあ次は…チャッピーって、何色が見えてるの？」愛奈「ママも知りたい！」（11/4で抜いた声をそのまま使う） |
| ② | AI「犬は何色が見えると思いますか？」→ 莉奈「えっと…白黒？」 |
| ③ | AI「青と黄色のボールと、赤いボールで確かめてみよう」 |
| ④ | チャッピーが青いボールにはすぐ気づくのに、赤いボールを見失う → 莉奈「赤いボール、見えにくいんだ！」 |
| ⑤ | 莉奈「じゃあ、チャッピーには空は何色に見えるの？」→ どんどん深まる |
| ⑥ | 愛奈の想い：【希が書く】方向性：「なんで？」が「次のなんで？」を連れてくる。親はそれを止めずに、一緒におもしろがるだけでいい |
| 最後 | 「"なんで？"は、次の"なんで？"を連れてくる。」→ フォローしてね |

事実の確認：犬は青と黄色は見分けやすく、赤と緑は見分けにくいと言われている。

希に聞きたいこと
1. 子どもの「なんで？」が止まらないとき、大人はどんな気持ちになる？希なら、どう付き合いたい？
2. 子どものころ、「なんで？」をおもしろがってくれた大人はいた？
