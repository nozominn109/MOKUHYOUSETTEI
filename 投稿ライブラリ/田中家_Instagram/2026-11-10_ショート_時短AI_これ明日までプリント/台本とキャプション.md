親の悩み：夜になって「これ明日まで」とプリントを出される。何度言っても出さない
使う考え方：課題の分離（アドラー心理学）。親が全部管理するのではなく、子どもが自分で写真を送る仕組みに
| 秒 | 中身 |

| 9〜12 | 愛奈「次からは、もらったらすぐ写真送って」蒼「…わかった」 |
| 12〜15 | 次の日、愛奈のスマホに蒼から写真が届く（ピコン）。愛奈がにっこり → フォローしてね |

## 決定稿（11/7・希と作成）
希が決めたこと：哲は「…あ、俺も会社の書類、明日までだった」／次からのルールは蒼が自分で決める／最後の愛奈は声なしでにっこり、心の声を吹き出しの文字で出す

| 秒 | 中身 |
|---|---|
| 0〜2 | 文字「夜10時。『これ明日まで』」 |
| 2〜4 | 蒼が目をそらしたまま、くしゃくしゃのプリントを差し出す「…これ、明日まで」。愛奈フリーズ |
| 4〜5 | 哲「…あ、俺も会社の書類、明日までだった」 |
| 5〜9 | 愛奈がプリントを撮る → スマホ画面のアップ：吹き出し「締め切りと持ち物だけ教えて」→ AI「締め切り：明日／持ち物：〇〇／親がやること：〇〇」（名前はぼかしてある） |
| 9〜12 | 愛奈「どうしたら、明日までにならないかな？」蒼（目をそらしたまま）「…もらったら、写真送る」 |
| 12〜16 | 次の日、愛奈のスマホに蒼から写真が届く（ピコン）。愛奈はにっこり（声なし）。心の声の吹き出し「自分で決めたことは、ちゃんと続くんだね」→「田中家の続きは平日20時。フォローしてね」 |

- 家の中なので全員靴なし。蒼はシャイ。プリントの名前はぼかす。AIラベルをオン

キャプション案：
夜10時。「これ明日まで」📄（あるある…）

アドラー心理学の「課題の分離」。プリントの管理は、本人の課題。親は問いかけて、任せるだけ。
