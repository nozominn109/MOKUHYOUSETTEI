# 11/9（月）ショート「夕飯で使える親子の質問」（15秒）［昨日の献立の続きもの］

- 状態：骨組み（15秒。11/6の献立の続き）
- 動画ファイル：田中家のセッションのGitHub（nozominn109/Instagram-DOUGA）の「投稿ライブラリ」の同じ名前のフォルダ

親の悩み：夕飯の食卓が静か。子どもはスマホ。「どうせ会話ないやん」と言われる
使う考え方：問いで引き出す（コーチング）。禁止より「楽しい問い」で、スマホを置きたくなる時間に
| 秒 | 中身 |
|---|---|
| 0〜2 | 文字「ごはんはできた。でも、食卓がしーん…」 |
| 2〜5 | 蒼はスマホ、莉奈はぼんやり、哲はテレビ。チャッピーだけがこっちを見ている |
| 5〜8 | 愛奈がAIに「家族みんなが答えたくなる質問を1つだけ」→ 画面に「1日だけ大人と子どもが入れかわったら、何する？」 |
| 8〜12 | 莉奈「パパの会社行って寝る！」哲「バレるって！」蒼が頬づえのまま、ぼそっと「…俺は〇〇」（スマホを置いている） |
| 12〜15 | 愛奈【ママの想い：希が書く】（方向性：スマホを取り上げなくても、話したくなる問いがあれば、自然に置かれる）→ フォローしてね |
- 蒼の答え〇〇は希が決める（例：「学校休む」「ゲームの大会出る」）
- 最後のひと工夫（キャプション）：お願いの文「家族みんなが答えたくなる、重くない質問を1つだけ出して」
- 希に聞きたいこと：①子どものころ、家族の食卓でいちばん覚えている会話は？ ②食事中のスマホ、希はどう思う？
- キャプション案：
  ごはんはできた。でも、食卓がしーん…🍚
  スマホを取り上げる前に、AIに「家族みんなが答えたくなる質問」を1つだけ出してもらいました。
