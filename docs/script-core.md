# 台本の軸（希の想い）

田中家の台本とすべての投稿で、毎回ここに立ち返るためのメモです。
第1話を手直しして入れた想いをもとに、希が直して育てていきます（たたき台：2026年11月1日）。

## 台本のつくり方：骨組みはClaude、感情は希
- Claudeがつくるのは骨組み：親の悩み、あらすじ、場面、セリフのたたき台、最後のひと工夫
- 希がするのは、感情を盛り込むこと：自分の体験、そのときの気持ち、自分の言葉。人にしかできない、いちばん大事な作業
- Claudeはネタごとに「希に聞きたいこと」をつける（例：この場面、希ならどんな気持ちになる？／自分の子ども時代や家庭で、似たことはあった？）。答えを台本に入れれば、感情が乗る

## いちばん伝えたいこと
- AIは怖いものではなく「相棒」。怖いのは「分からないから」
- 「使わせる・使わせない」ではなく、「どう使うか」を親子で考える
- AIは答えを出させる道具ではなく、子どもの考えを引き出してくれる相棒（第1話の軸）

## 大事にしていること
- 主役は親子の会話と絆。AIは裏方
- 親がまず体験する。正しい知識と倫理観をもって使う
- 子どもがAIに振り回されず、AIを使って夢を叶えられるように
- 時代に取り残されない親子に
- 誰でも、人より少し知っていることで誰かの役に立てる（お役立ち）
- 子育ては親みんなのもの。「ママ」に限定しない（パパ、シングルの親、祖父母も）

## 毎話の出発点（第1話で希がいちばん考えたこと）
- 「この場面で、AIを"一緒に考える相棒"にするにはどうしたらいい？」から台本を考える
- AIにさらりと解決させない。AIは考えるきっかけや問いをくれる存在で、考えて決めるのは人（子どもと親）
- ママは希の分身。毎話、ママがAIに対する考えを自分の言葉で語る場面を入れ、希の意見をママを通して伝える

## 台本の決まりごと
- ひとつの話に、ひとつの悩みと、ひとつの答え
- 骨組みでは、ママがAIについて語るセリフを【ママの想い：希が書く】と空けておき、方向性のメモだけ書く
- 最後は温かく、前向きに終わる
- 暴力的なこと、つらいイメージ（自傷、いじめの場面、重い病気など）は田中家の投稿に入れない。悩みは、見る人が明るい気持ちで受け取れる場面で描く
- 親子で今日から試せるひと工夫（プロンプトや声かけ）を、毎回ひとつ入れる
- 投稿するときは毎回「AI情報」のラベルをオンにする（AIで作った場面が1秒でも入っていたら必ず）。AIで作ったことを隠さないのは、「AIとの正しい付き合い方」を伝えるアカウントとしての姿勢でもある
- 物語の登場人物としての「ママ」はそのまま。キャプションの呼びかけやハッシュタグでは「ママ」に限定しない

## 映像のチェック（気づいたこと）
- 田中家のセッションで決まった制作ルール（docs/series_bible.md、Instagram-DOUGA側）：声は約1.4倍の速さ／同じ言葉（「じゃあ」など）を続けない、言い直しは切り取る／画面の上18%・下25%・右端に大事な文字やキャラの頭を置かない、ロゴは左上に小さく／同じ場面の絵を2枚作るときは席順をそろえる／手（左右・指の向き）が目立つポーズは避ける／毎回AIラベル
- 蒼は思春期でシャイ。元気に手を挙げるより、頬づえ・目をそらすなどが合う
- ショート1本の制作は希の作業で約1.5〜3時間（Klingは1本約150〜300クレジット）。週5本すべて新しく作ると重いので、使い回せる回を混ぜる
- 家の中の場面では、靴をはかせない（靴下・素足・スリッパ）。Klingの指示にも毎回「室内、靴なし」を入れる。11/4の莉奈がスニーカーのままだった

## テンポと続きもの（11/4の制作で決まったこと）
- テンポは速めにする（11/4の約36秒の速さが基準）
- ショートはさらに短く、10〜15秒の超ショートを基本にする（希の判断。第1話の平均再生が14秒だったので、15秒なら最後まで見てもらいやすい）。1本に1テーマ。説明はキャプションへ
- 希が続きものにした理由（11/4〜11/5）：長くなった動画を見やすい長さに分けるため。そして「AIと一緒なら、知りたいをどんどん深掘りできる」ことを、2話にわたって伝えるため
- 続きものにしてもよい。前の回の最後に予告（例：「明日、莉奈の"なんで？"はまだ続く…👀」「続きは明日20時。フォローしてね」）を入れ、キャプションの最後にも1行入れる。予告したら、次の日は必ず続きを出す

## 言葉づかい
- 決まった「入れたい言葉」「使わない言葉」はなし。気になる言葉は、台本をつくるたびに希が直す

## お悩み募集（田中家にお悩み相談）
- 毎週水曜のストーリーズで質問箱を出す：「田中家に相談してみませんか？子育てや、子どもとAIのこと。いただいたお悩みが、田中家のお話になるかも」
- 届いたお悩みはネタ帳へ。お話にするときは、本人だと分からないように場面や設定を変える。キャプションに「いただいたお悩みをもとに、内容を一部変えています」と入れる
- つらすぎる内容（自傷、虐待、重い病気など）は田中家のお話にしない。必要なら希が個別に、専門の相談先を伝える
- 医療・法律などの専門的な判断は答えない
