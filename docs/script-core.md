# 台本の軸（希の想い）

田中家の台本とすべての投稿で、毎回ここに立ち返るためのメモです。
第1話を手直しして入れた想いをもとに、希が直して育てていきます（たたき台：2026年11月1日）。

## 台本のつくり方：骨組みはClaude、感情は希
- Claudeがつくるのは骨組み：親の悩み、あらすじ、場面、セリフのたたき台、最後のひと工夫
- 希がするのは、感情を盛り込むこと：自分の体験、そのときの気持ち、自分の言葉。人にしかできない、いちばん大事な作業
- Claudeはネタごとに「希に聞きたいこと」をつける（例：この場面、希ならどんな気持ちになる？／自分の子ども時代や家庭で、似たことはあった？）。答えを台本に入れれば、感情が乗る

## シリーズを表すママの言葉（紹介リールで希が決めた）
「AIに聞いて答えを教えてもらうんじゃなくて、一緒に考える相棒に。田中家の"どう使う？"、はじまります」

## いちばん伝えたいこと
- AIは怖いものではなく「相棒」。怖いのは「分からないから」
- 「使わせる・使わせない」ではなく、「どう使うか」を親子で考える
- AIは答えを出させる道具ではなく、子どもの考えを引き出してくれる相棒（第1話の軸）

## 大事にしていること
- 主役は親子の会話と絆。AIは裏方
- 親がまず体験する。正しい知識と倫理観をもって使う
- 子どもがAIに振り回されず、AIを使って夢を叶えられるように
- 時代に取り残されない親子に
- 誰でも、人より少し知っていることで誰かの役に立てる（お役立ち）
- 子育ては親みんなのもの。「ママ」に限定しない（パパ、シングルの親、祖父母も）

## 毎話の出発点（第1話で希がいちばん考えたこと）
- 「この場面で、AIを"一緒に考える相棒"にするにはどうしたらいい？」から台本を考える
- AIにさらりと解決させない。AIは考えるきっかけや問いをくれる存在で、考えて決めるのは人（子どもと親）
- ママは希の分身。毎話、ママがAIに対する考えを自分の言葉で語る場面を入れ、希の意見をママを通して伝える

## 台本の決まりごと
- ひとつの話に、ひとつの悩みと、ひとつの答え
- 骨組みでは、ママがAIについて語るセリフを【ママの想い：希が書く】と空けておき、方向性のメモだけ書く
- 最後は温かく、前向きに終わる
- 暴力的なこと、つらいイメージ（自傷、いじめの場面、重い病気など）は田中家の投稿に入れない。悩みは、見る人が明るい気持ちで受け取れる場面で描く
- 親子で今日から試せるひと工夫（プロンプトや声かけ）を、毎回ひとつ入れる
- 物語の登場人物としての「ママ」はそのまま。キャプションの呼びかけやハッシュタグでは「ママ」に限定しない

## 言葉づかい
- 決まった「入れたい言葉」「使わない言葉」はなし。気になる言葉は、台本をつくるたびに希が直す
