# MUSUBIの軸（Threads・お役立ちの輪）

ThreadsはAIのアカウントとは別の、腸活講師のアカウント「MUSUBI」で投稿します。AIや田中家には触れません。

## はじまりの言葉（ココ・シャネル）
「道端に咲いている花の名前を一日に一つ覚える。それだけで世界の謎が一つ解けた気になる。だからこそ、人生は楽しく、生きることは素晴らしいのよ。」

## 趣旨
- 誰でも、人より少し詳しいことがある（漫画、料理、片づけ、仕事の小ワザ…）。希の場合は腸活
- その「ちょっと知っている」を、知りたい人に教える。誰かの世界がひとつ広がる
- 人脈づくりの会ではなく、「ちょっと役に立てた」がうれしい集まり
- 専門家でなくていい。「私に話せることなんてない」という人も歓迎
- 年代も性別も問わない。20代でも60代・70代でも、垣根なく
- 一緒に参加する仲間は名前を出さない（例：凛華ちゃん →「20代のAIに詳しい子」）。AIは、その人の得意なこととして触れる程度にとどめる

## 希について
- 名乗り方：「腸活講座の講師をしている、腸活愛好家のNOZOMIです」（名刺の肩書きも「腸活愛好家」）
- 腸活講座の会場：姪浜のコミュニティプラザgokant。プロフィールの自己紹介には入れる。投稿の「はじめまして」には入れない
- 何をしている人かは、プロフィールやInstagramを見ればわかるので、投稿で説明しすぎない

## 投稿の中身
- お役立ちの想い（シャネルの言葉がきっかけ）
- 腸活の小さな知識（講座での言い方に合わせて希が直す）
- 「あなたがちょっと詳しいことは？」などの問いかけ（集まった声がランチ会の参加につながる）
- お役立ちランチ会・腸活講座のお知らせ

## 書かないこと
- AI、田中家、AiNAの話
- 希の体験を勝手につくること（体験は【】で空けて、希が書く）
- 医療の効果を言い切ること
