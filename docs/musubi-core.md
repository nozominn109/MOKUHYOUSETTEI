## 希の想い（自己紹介に入れた言葉）
若い世代の新しい知識も、大人世代の社会経験や暮らしの知恵も。世代をこえて教え合える素敵なコミュニティをつくりたい。Z世代も60代以上の方も、世代に関係なく参加OK

## 趣旨
- 誰でも、人より少し詳しいことがある（漫画、料理、片づけ、仕事の小ワザ…）。希の場合は腸活
- その「ちょっと知っている」を、知りたい人に教える。誰かの世界がひとつ広がる
- 人脈づくりの会ではなく、「ちょっと役に立てた」がうれしい集まり
- 専門家でなくていい。「私に話せることなんてない」という人も歓迎
- 世代をこえたつながり：20代の新しい知識も、60代・70代の暮らしの知恵も、どちらも誰かの役に立つ。「年齢制限なし」のような事務的な言い方ではなく、若い世代も上の世代も「行ってみたい」と思える言い方で誘う。男性も女性も歓迎
- 一緒に参加する仲間は名前を出さない（例：凛華ちゃん →「20代のAIに詳しい子」）。AIは、その人の得意なこととして触れる程度にとどめる

## 希の腸活の考え（講座で伝えていること・11/8に希から）
- 腸活は発酵食品だけではない。バランスの取れた食生活、睡眠、運動。この全部が腸活
- 日本人には、日本人に合った腸活がある。それがいちばんコスパもタイパもいい
- ヨーグルトなどの乳酸菌の多くは、腸にすみつかずに通り過ぎる「通過菌」
- 麹由来の発酵食品（味噌、しょうゆ、甘酒など）をとるのが、コスパもタイパもいい。麹菌は生きていても死んでいても、菌体そのものが腸内細菌の大好物
- 下書きの例は、和の発酵食品を中心にする。食べ物だけでなく、睡眠や運動の小さなコツも混ぜる

投稿で書くときの言い方（医療の効果を言い切らないため）
- 「〜と言われています」「〜という研究もあります」を添える
- 通過菌は日本人だけの話ではない（多くの乳酸菌は、だれの腸でもすみつきにくい）。日本人らしさは「昔から和の発酵食品を食べてきた」「海藻を分解できる腸内細菌を持つ人が多い、という研究がある」などで伝える
- 麹菌は細菌ではなくカビの仲間（「菌」と書くのはOK）
