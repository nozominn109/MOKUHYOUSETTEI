# 子育て法から借りるネタ帳（田中家・投稿用）

世間でよいと言われている子育ての考え方から、田中家の話に使える「型」をまとめたもの。考え方の名前はキャプションで紹介してよい（検索にもつながる）。本の文章はそのまま使わない。AIは答えを出さず、親が考えるきっかけ（問い）をくれる役にする。

| 考え方 | 中身（ひとことで） | 田中家の話のたね | NG → OK の言いかえ |
|---|---|---|---|
| 課題の分離（アドラー心理学） | 勉強するかどうかは子どもの課題。親は口を出しすぎず、相談されたら手伝う | 「勉強しなさい」が止まらない愛奈。AIに「それは誰の課題ですか？」と聞かれてはっとする | 「勉強しなさい」→「何時から始める？困ったら言ってね」 |
| 勇気づけ（アドラー心理学） | 上からほめるより、「ありがとう」「助かった」と気持ちを伝える | お手伝いした莉奈に「えらいね」ではなく「助かったよ」 | 「えらいね」→「ありがとう、助かった」 |
| Iメッセージ（ゴードン博士の親業） | 「あなたは〜」と責めるより、「私は〜と感じる」と伝える | 夜ふかしの蒼に、愛奈が言い方を変える | 「早く寝なさい！」→「夜ふかしが続くと、ママは心配なんだ」 |
| 能動的な聞き方（親業） | 子どもの言葉や気持ちを、そのまま受け止めて返す | 「部活やめたい」と言う蒼に、理由を聞く前に「やめたいくらい、しんどいんだね」 | 「なんで？」→「そう思ったんだね」 |
| 選択肢をわたす | 命令ではなく、子どもが自分で選べる形に | お風呂と宿題、どっちが先？を莉奈が選ぶ | 「早くお風呂入って」→「お風呂と宿題、どっちを先にする？」 |
| 過程をほめる（成長マインドセット） | 結果や才能より、努力ややり方をほめる | テストの点を聞く哲と、がんばりを見ていた愛奈 | 「100点すごい！」→「毎日コツコツやってたもんね」 |
| 先回りしない・失敗させる勇気 | 転ばぬ先の杖を出しすぎない。小さな失敗から学ばせる | 忘れ物を届けに行こうとする哲（おっちょこちょい）を愛奈が止める | 「ママが持っていくよ」→「どうしたら忘れないと思う？」 |
| 安全基地（愛着の考え方） | 思春期は離れていく時期。いつでも帰れる場所でいることが大事 | 第2話の流れ。話さなくても、帰ってこられる家 | 「なんで何も言わないの」→「いつでも聞くからね」 |
| 問いで引き出す（コーチング） | 答えを教えるより、質問で子どもの考えを引き出す | シリーズの軸そのもの。AIが親に問い、親が子に問う | 「こうしなさい」→「どうしたらいいと思う？」 |
| 自分で決める・有能感・つながり（自己決定理論） | 自分で決められる、できた感じがある、大事にされている。この3つがやる気のもと | 家族のAIの約束を、莉奈と一緒に決める（11/5の話） | 「ルールはこれね」→「一緒に決めよう」 |
