# MUSUBI 会員カードと「お役立ちスタンプカード」

## 会員カード（横長 3:2・大理石とバラの背景）
- 作り方：`node tools/musubi_cards.js O`（`tools/musubi_cards.js` の `CARDS` に名前・番号・入会日・「ちょっと詳しいこと」を書く）
- 保存先：`投稿ライブラリ/MUSUBI_会員カード/`（No001_NOZOMI／No002_RINKA／No003_SAYAKA）
- 形：「MUSUBI」を大きく、会員番号は小さめ。「Community Member's Card」、金の「はじまりの10人」の輪（その人の番号の点だけ金の丸で囲む）、下に「So glad I met you」（5本のバラの花言葉）
- 背景：ChatGPTで作った画像 `背景_大理石と5本のバラ.webp`
- No.003：SAYAKA、入会日 2026.11.12、ちょっと詳しいこと「自分を生きる人」（第1回ランチ会 11/12で入会）
- 名前入りのカードは本人にだけ渡す。Threads（MUSUBI）には載せない

## お役立ちスタンプカード
- 考え方：参加するだけで、誰かのお役に立っている。話すたびに、誰かに新しい発見をひとつ（カードの上のひとことに入れた）
- スタンプはお花。1回ごとにちがう花で、花言葉も楽しんでもらう。6個そろったら「お楽しみがあるかも」と匂わせる（中身は未定。プチプレゼントを考え中）
- 渡し方：ランチ会の場で、希のスマホでその場で作って渡す（LINE公式のショップカードは使わない）
- ページ：https://claude.ai/artifact/GkszUT5SZHGUY4UpRvqoo1 （希だけが開ける。名前・番号・スタンプの数・日付を入れて「画像を作る」→長押しで保存。Claudeのアプリの中では長押し保存ができないので、ブラウザ（Safariなど）で開くか、「大きく表示する」でスクリーンショット）
- 元ファイル：`tools/stamp_page_template.html`。作り直しは `python3 tools/build_stamp_page.py 背景.jpg 出力.html`（背景は大理石の画像に色味をつけたもの）。公開は Artifact で同じファイルを公開し直す
- お花の順番（花言葉は希が選んだもの）
  1. 5本のバラ：あなたに出会えてよかった（花束の写真のスタンプ。ChatGPTで作成）
  2. バーベナ：家族の和合・団結
  3. ジャーマンアイリス：素晴らしい出会い
  4. ハーデンベルギア：出会えてよかった
  5・6：未定（希が花言葉と一緒に選ぶ）
- 2〜4個目は、いまは文字のスタンプ。花の画像（ChatGPTで作成）ができたら、バラと同じ形で入れる
- 決まっていないこと：スタンプの数（いまは6）、6個そろったあと（2冊目にするか）、プチプレゼントの中身
